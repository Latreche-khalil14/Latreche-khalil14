### Featured Projects

<table>
<tr>
<td width="50%" valign="top">

#### 🔍 Explainable AI-Driven Resume Intelligence
*Bachelor's Thesis · Supervised by Dr. Kissoum Yacine*

- **Problem:** Conventional automated screening processes operate as opaque black boxes, providing candidates and evaluators with zero transparency or actionable insight into decision criteria.
- **Solution:** Designed a multi-agent framework coordinating candidate profile extraction, semantic vector matching via ChromaDB, and SHAP-based feature attribution to generate interpretable evaluation summaries.
- **Stack:** `Python` · `LangChain` · `ChromaDB` · `SHAP` · `FastAPI` · `Redis`

[**View Repository →**](https://github.com/Latreche-khalil14)

</td>
<td width="50%" valign="top">

#### 🧠 Local Multi-Modal RAG Knowledge Platform
*Document Intelligence & Reasoning Pipeline*

- **Problem:** Cloud-dependent LLM services introduce external data governance concerns and obscure the intermediate retrieval and reasoning steps that produce answers.
- **Solution:** Implemented a self-hosted RAG platform using local open-weight models via Ollama and FAISS embeddings, streaming step-by-step reasoning and latency telemetry to the client via Server-Sent Events (SSE).
- **Stack:** `Python` · `FastAPI` · `FAISS` · `LangChain` · `Ollama` · `React` · `TypeScript`

[**View Repository →**](https://github.com/Latreche-khalil14/chat-bot-)
